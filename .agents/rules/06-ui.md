# WAJIB: shadcn/ui + Tailwind v4

> Semua UI baru dibangun di atas fondasi yang sudah ada. Jangan bikin sistem desain tandingan.

## Aturan

- **WAJIB** memakai komponen shadcn/ui untuk UI baru (tombol, form, dialog, tabel, badge, dsb). Referensi instalasi: https://ui.shadcn.com/docs/installation/tanstack
- Tambah komponen hanya lewat CLI: `bunx shadcn@latest add <nama>`. Konfigurasi terkunci di `components.json`: style `new-york`, base `zinc`, alias `#/components`, `#/lib/utils`, `#/components/ui`, `#/lib`, `#/hooks`.
- **WAJIB** memakai Tailwind v4 (via `@tailwindcss/vite`, entry `src/styles.css`). Styling lewat utility class; **DILARANG** menambah file CSS global baru atau framework CSS lain.
- **DILARANG** menulis ulang komponen yang sudah ada di `src/components/ui/` — impor dan pakai. Varian dibuat lewat `cva`/`class-variance-authority` mengikuti pola bawaan, bukan fork file.

## Grafik (chart)

- **WAJIB** memakai komponen grafik shadcn/ui (`ChartContainer`, `ChartConfig`, `ChartTooltip`, `ChartLegend` dari `#/components/ui/chart`) untuk semua grafik/tren (mis. kurva gaji sakit, rekap presensi, statistik cuti). Referensi: https://ui.shadcn.com/docs/components/chart
- `chart.tsx` belum ada? Tambah lewat CLI: `bunx shadcn@latest add chart` (menarik `recharts` yang sudah terpasang di `package.json`).
- **DILARANG** memakai `recharts` langsung atau pustaka grafik lain (Chart.js, ApexCharts, dsb); grafik selalu dibungkus `ChartContainer` + `ChartConfig` agar warna mengikuti token tema.

## Ikon

- **WAJIB** memakai **lucide-react** untuk semua ikon. Impor langsung: `import { CalendarDays } from 'lucide-react'`.
- Ukuran mengikuti pola yang ada (mis. `className="size-4"`); **DILARANG** menambah pustaka ikon lain atau menulis SVG inline sendiri bila lucide menyediakannya.
